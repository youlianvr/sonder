# Sonder — сборки

Здесь лежат только собранные APK. Исходники — в отдельном приватном репозитории.

## Установка

1. Скачай свежий APK: **[страница релизов](https://github.com/youlianvr/sonder/releases)** или
   постоянная ссылка `https://ds-clone-api.youlianvr.workers.dev/download` (она всегда отдаёт последнюю сборку).
2. Открой файл на телефоне. Android спросит разрешение на установку из этого источника — разреши.
3. Открой Sonder и нажми «Войти через Telegram». Приложение покажет код, бот попросит
   отправить его командой `/start КОД`. Владелец подтвердит доступ — и вход завершится сам.

Нужен Android 8 или новее, телефон на arm64 (это все телефоны с 2018 года).
Если у тебя старый аппарат и сборка `arm64` не ставится, возьми `universal` из того же релиза —
она тяжелее, но работает везде.

## Обновления

Приложение само проверяет, есть ли сборка новее: полоса «Доступна версия …» появляется
прямо в приложении. Настройки → «Проверить обновления» — то же самое вручную.
Установка поверх старой версии сохраняет чаты и вход.

## Что это

Sonder — мобильный клиент для чата с моделью. Вход только через Telegram, переписка
хранится на телефоне и синхронизируется с сервисом. Политика конфиденциальности:
`https://ds-clone-api.youlianvr.workers.dev/privacy`.
